    Optionalmode

    mode?: "set-position" | "follow-pointer"

    If mode is set-position the overlay remains at the provided position. The position can be changed manually by calling setPosition on the overlay instance. If mode is follow-pointer the position is automatically updated to pointer position (coordinates) on the map.

    By default the mode is set-position.
