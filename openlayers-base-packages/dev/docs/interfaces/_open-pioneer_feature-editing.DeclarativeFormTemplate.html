    Interface DeclarativeFormTemplate

    Form template using a declarative field configuration approach.

    Defines a form using an array of field configurations. Each field in the fields array specifies the type of input control (text field, checkbox, select, etc.) and its properties. The form is automatically rendered based on these configurations.

    This is the recommended approach for most use cases as it provides a structured, declarative way to define forms without writing custom rendering logic.
